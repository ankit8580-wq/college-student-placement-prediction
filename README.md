# College Student Placement Prediction

A machine learning project that predicts whether a college student is likely to get placed based on academic performance and other student-related factors.

## 📌 Project Overview

The objective of this project is to build a machine learning classification model that predicts student placement outcomes using features such as CGPA, IQ, communication skills, projects completed, and other relevant factors.

## 📊 Dataset

- Number of samples: 10,000
- Problem type: Binary Classification
- Target variable: Placement
- Classes: Yes / No

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Jupyter Notebook

## 🤖 Machine Learning Model

The project uses Logistic Regression as the initial classification algorithm.

The workflow includes:

1. Data loading
2. Data preprocessing
3. Feature selection
4. Data visualization
5. Train-test splitting
6. Feature scaling
7. Model training
8. Prediction
9. Accuracy evaluation
10. Decision-region visualization

## 📈 Features

Some of the important features used for prediction include:

- CGPA
- IQ
- Communication Skills
- Projects Completed
- Other student-related factors
